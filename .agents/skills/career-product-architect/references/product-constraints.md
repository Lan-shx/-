# Product constraints

PRODUCT.md is the authoritative feature contract. Preserve 职业探索 and 对比分析 as primary modules, market explorer as default core. Core analysis, all filters, mappings, real jobs, provenance, local plans, imports and exports remain accessible after navigation consolidation. Visual simplicity is not permission to delete capabilities.

Use the locked historical 69,465-record snapshot; do not restart collection. Distinguish recorded jobs, unique listings, employers, advertised headcount and confirmed live vacancies. Growth/competition unavailable until matching historical/supply data exists. Every chart answers one user question and links to underlying evidence. Salary n<10 is unavailable, never zero. Avoid repeated scope/metrics as filler.

New user instructions supersede historical notes. Unsupported mock values in a design example are examples, not data to implement.
