# Chart contract

For every chart specify user question, metric, units, denominator, encoding, scale, legend, missingness, interaction, drill-down, provenance and keyboard/mobile alternative. Do not default to radar charts. Selection locks a detail object without changing global filters; explicit drill-down does. Map positions are sourced city anchors, not employer coordinates. Keep source/license with geographic assets. No fabricated confidence labels, growth, competition or illustrative counts in production.
