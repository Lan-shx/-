## 当前改版（2026-10-07）

本次改造保留原始 69,465 条历史记录及全部数据分块，未扩采或更新记录日期。三个主要入口组织职业发现、方向比较和市场证据；市场证据包括总览、城市地图、职业×城市矩阵和行业结构。317 个明确城市组可查，地图未定位城市保留在数字表。专业映射与跨页面筛选保持同步，图表选择先展示局部证据，再由用户执行范围下钻。

大屏采用独立的深色布局：中心地理地图、两侧职业/城市前六排名、底部行业披露及选中证据。完整城市数字表和修改范围可达，退出大屏保留范围与选择。普通界面与大屏共享数据。

旧分析、真实岗位、收藏、方案、导入、CSV、SVG 和完整离线 HTML 导出保留。连续趋势、竞争及供需指标没有可用数据，不推断展示。低于 10 个有效月薪样本不显示工资统计。完整离线 HTML 约 145 MB，适合归档；轻量分析可导出 CSV。可重复的本地可视化构建文件位于 viz-build；验证证据见 SHIP-REVIEW.md。

主导航为发现、比较、市场快照、趋势、岗位、我的，默认进入发现；数据说明为辅助入口。保留第五版发现页的职业/城市/门槛入口、方向候选比较、真实岗位对比、本机收藏与方案。

市场快照由第五版市场探索器提升为同级主功能。默认岗位×城市样本矩阵，显示前8方向×8城市；点击交叉点全局切换，矩阵为保持可探索性放宽岗位与城市、沿用其他筛选。色阶为实际招聘记录数，标注样本与日期口径，多城市记录不能相加。下方结构拆解包含经验100%堆叠、薪资四分位、行业、明示企业规模、技能与学历，点击结构返回相关岗位。

顶部全站常驻专业、岗位、城市、日期、关键词、最低经验、学历和应届/实习条件；全部筛选按钮可见，其他已应用条件以标签显示并可清除。跨功能保留范围。默认沿用第五版全部快照范围；选择相对日期窗以采集日为末端，明示是更新/发布日期筛选，不是实时招聘市场。

## 统一市场探索器（2026-10-04）

导航收敛为发现、比较、趋势、岗位、我的，数据方法与市场探索器放在更多中。发现下保留职业、城市、门槛三个任务入口。原模块网址只作为兼容链接转入探索器，不再呈现11模块导航。

探索器按研究对象、机会/薪资/门槛/招聘企业/应届机会/数据质量及比较分组组合成一张主图。默认横向条形图，箱线、分布、累计分布、热力、气泡藏在切换视图。图标题下固定读图说明；热力数值图例、气泡面积和箱线语法统一，数字表折叠，说明包含统计方法、样本与缺失限制。

全局范围栏适用于每个页面；原筛选表收进唯一抽屉，删除独立模块条件。研究对象应用到全局范围。企业名称与明确应届/实习新增为可复用过滤条件。职业卡片收起薪资样本、四分位、来源与披露率；自己分析操作自动带入方向。少于10条有效薪资的组始终留空，不可调低门槛。

`node qa-explorer.mjs` 验证统一范围、抽屉、6类指标和6种视图、上下文传递、图例、空结果、企业/应届条件、手机、离线与旧链接兼容。原qa-decision.mjs、qa-business.mjs记录旧界面验证流程，不适用于取消11模块后的导航。

## 职业决策层（2026-10-04）

首页以专业、城市和探索优先级开始，从同一数据底座生成职业方向卡片，提供机会量、有效薪资样本、月薪中位数、四分位区间、招聘方、城市与门槛披露率。专业映射仅为探索线索，少于10条有效薪资不显示统计值。

决策导航包含发现职业、最多3方向比较、实际城市机会表、学历/经验/技能要求、趋势证据限制、真实岗位、职业方案和数据方法。原11模块已经整合进统一市场探索器。候选方向、备注与显式保存的方案范围存储在当前浏览器，可导出带原始岗位链接的Markdown；无服务端个人账户存储。离线HTML包含完整数据与两个产品层。

趋势、竞争及供需仍等待对应连续或供给侧数据，不以发布日期分布代替增长，不推断个人适配评分或起薪。`node qa-decision.mjs` 验证决策流程、11模块、本机保存、原页入口、移动端和离线数据。

## 真实招聘快照

一次性采集，范围为2025-10-03至2026-10-03公开招聘记录。发布底座要求至少50,000条去重有效记录。最终数量、候选池、来源分布、排除原因和随机种子由dist/jobs.json的sampling记录，以最终数据检查结果为准。

中国公共招聘网使用官方匿名HTML列表：固定公开页范围，种子20261003随机排列分页，读取页内全部记录后按职业与时间核验，不设置城市或岗位数量配额。国家大学生就业服务平台使用匿名公开查询，每个查询最多读取公开前5页，补充面板包含297个大陆城市查询；公开排序和查询范围具有偏差。字节跳动通过正常招聘页面的运营、产品、职能、销售、市场类别及分页采集。腾讯延用已核验官网记录。无法核验近一年日期的旧记录不混入本次样本。

在可核验候选池内使用固定种子不放回抽取50,000条。该随机性仅针对采集池，不代表全市场等概率随机样本。按岗位URL和公司、标题、明确工作城市集合去重。多城市岗位是一个条目，参与多个城市分组时不能把城市数量相加。腾讯岗位URL的postId是岗位标识，不去除。

地区统一按明确地级城市或行政区代码处理。重点就业城市独立展示，其余明确大陆就业地区合并为“其他大陆城市”。省份和未知位置不放入城市选择，也不充作其他城市；未知城市默认排除，可通过高级筛选包含。就业平台省级列表通过公开详情补齐，禁止从公司名称或查询城市推断工作地点。

发布时间、平台维护时间、采集日期和截止日期分别保存，缺失不互相代填。公共招聘网发布日期使用原站“发布日期”筛选对应s_aae397，平台维护日期为s_uptime，截止日期为s_aae398；s_aae396单独保存为平台记录日期，不冒充发布日期。发布日期或维护日期至少一个在近一年内才入池。已明确截止按浏览器大陆当前日期判断；“未明确截止”不保证仍在招。失败详情保留未知，不当作零岗位或已截止。来源链接、采集记录、分类与统计口径可在工作台核对，完整来源记录可下载CSV。未绕过登录、验证码或访问限制。

原始响应与不可发布采集池在本机raw和*-pool.json，均不打包。构建器输出带行数和SHA-256的分片清单，每片最多5,000条，提供gzip与JSON回退。浏览器校验哈希和完整行数后分析，缺失分片不显示不完整底座。离线HTML仍内置完整快照。

## 筛选与呈现

全局筛选：专业、岗位方向、关键词、大陆城市、行业、来源、最低经验、统一学历层级、规模、性质、工作性质、招聘渠道、截止状态、技能、日期口径、时间窗、薪资区间及其匹配方式。同一维度取并集，不同维度取交集；技能支持任一/全部。日期筛选可保留未知，薪资范围支持重叠、区间包含或中点匹配。

模块独立记忆职业聚焦条件；赛道模块沿用原版职业映射。全局范围、本模块范围与图表呈现相互区分。主图可切换柱状、箱线、累积分布和热力图，同时保留辅助图。默认模块还包含气泡、环形、100%堆叠、经验分位曲线、雷达与更新时间分布。图表可查看原始分组数，并在支持的分组下钻。薪资分组最小样本可调，缺失值不补零。显式选择的城市不受前N组截断；样本不足时保留名称、行数和空位，数字表明确提示。

薪资采用税前月薪区间中点；P25/P50/P75线性插值。未披露排除；额外薪数不折算。箱线须线展示极值，未作Tukey异常值裁剪。经验曲线是横截面分组，非个人成长预测。雷达各轴独立定标，非综合适配评分。更新时间分布不是市场增长。没有投递人数及匹配的供给记录，不计算竞争指数或供需错配。

岗位详情、收藏、最多3条对比、CSV/SVG/打印PDF/离线HTML/JSON配置导出保留。离线HTML内置图表引擎、样式、脚本和真实数据。导入CSV只替换浏览器当前会话，刷新恢复本站数据。

## 运行与验证

纯静态站点，无构建或服务端依赖：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory dist
python verify-data.py
node qa-business.mjs
node qa-cities.mjs
node qa-load.mjs
```

QA依赖本机qa-tools目录的Playwright及Chrome；验证11模块、组合筛选、模块条件记忆、薪资口径、日期范围、明细、对比、各主图、离线导出与移动端溢出。数据检查验证唯一性、原始URL、职业分类、薪资范围及日期。WebMCP为浏览器提供可选的读取与可见筛选工具；原生支持因浏览器而异，不作为使用前提。
